Third-party software in iai-gui.exe

iai-gui.exe is one Windows program made with PyInstaller. Its own code (the GUI, the iai-actuator-driver package and
the native library iai_actuator_driver.dll) is under the Apache License 2.0: see LICENSE and NOTICE. It also carries
the software below, each under its own licence. The full texts follow the list, or are in the file named.


WHAT IS INSIDE

Python (CPython, the version the About panel names)                  PSF-2.0                 PYTHON_LICENSE.txt, below
  python3XX.dll, the standard library modules the GUI imports and their extension modules (_ctypes, _socket,
  select, pyexpat, _decimal, _bz2, _lzma and a few more). PYTHON_LICENSE.txt is the licence file of the Python inside
  the exe: the PSF licence, the conditions of its Windows build and the bzip2 licence. Which of the other libraries the
  modules incorporate it also holds depends on the Python build, so this file holds their texts:
    libffi (_ctypes, libffi-8.dll)                    MIT                     below
    Expat (pyexpat)                                   MIT                     below
    libmpdec (_decimal)                               BSD-2-Clause            below
    zlib (zlib)                                       Zlib                    below
    HACL* (hashlib's own hash code)                   MIT                     below
    mimalloc (Python 3.13 and later)                  MIT                     below
    bzip2 (_bz2)                                      bzip2-1.0.6             PYTHON_LICENSE.txt
    XZ Utils liblzma (_lzma)                          public domain or 0BSD, by version: no notice required

Microsoft Visual C++ runtime (VCRUNTIME140.dll, VCRUNTIME140_1.dll)   Microsoft Distributable Code, redistributed with
  Python under the "Additional Conditions for this Windows binary build" in PYTHON_LICENSE.txt.

pySerial 3.5 (the serial package)                                     BSD-3-Clause            below

PyInstaller bootloader and loader                                     GPL-2.0-or-later WITH   below
                                                                      Bootloader-exception
PyInstaller run-time hooks                                            Apache-2.0              LICENSE

iai_actuator_driver.dll, built with zig (clang): libc++, libc++abi, libunwind, zig's compiler_rt and the mingw-w64
  runtime are linked in. Their notices are in NATIVE_THIRD_PARTY.txt, which is in this zip too.

Not in the exe: OpenSSL (ssl, _ssl and _hashlib are left out by apps/gui/iai-gui.spec), Tcl/Tk (tkinter is left out
too) and SQLite (nothing imports sqlite3). The GUI's pages, scripts and styles are this project's own; no third-party
web code.
