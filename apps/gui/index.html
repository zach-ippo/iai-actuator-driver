    Controls

    The first command after connecting also gives Modbus control of the axis, only while it is at rest (switching it during motion would stop the move); it is handed back to PIO on disconnect.

    Control mode (PMSS)

    PIO has control (PMSS = 0, as after every power-up). On hardware a Modbus STOP stopped a move commanded over Modbus with PMSS = 0; it is untested on a move a PLC commanded over PIO, so stop those from the PLC or with the hardware stop. The first command takes Modbus control while the axis is at rest.

    Configuration (each asks for confirmation; only at rest)

    A baud change is volatile: the EC answers at 38400 again after every power-up (the driver auto-detects the rate at connect). 115200 (code 0x14) and 230400 (0x15) are verified on hardware. 38400 (0x06) is taken by the EC-GRBP8M gripper and the PCON-CB and ignored by the EC-R6S rod (sent direct): the driver checks after the switch and says when a unit kept its rate; to get back to 38400, power-cycle the unit.

    Move

    Position table (read from the EC)
    Connect to load positions 0-2.

    Quick buttons move to the stored position using the speed and accel above, not the table's own speed.

    Run stored position (0x9800 = n: the row's own speed / accel, a push row pushes)
    Connect to load positions 0-2.

    Runs the row exactly as the EC stores it (asks first; a row faster than this session's caps needs a second confirmation). Modbus control is taken first: the EC ignores 0x9800 while PIO has control.

    Jog (relative move from the measured position)

    Sent as driver moves at the speed above. The EC's own JOG inputs are never used (they run at ~100 mm/s).

    Push

    This unit cannot push (its push cap is 0 %): push is disabled.

    No push yet

    Approaches at the speed above, then pushes over the band at min(speed, 20 mm/s) with the force limit (20–70 %; accel from the Move panel). Start on the approach side of the push zone. After contact the motor keeps pushing until the next move: move or jog away to release.
